Kokoro Reader (Chrome extension)

Install
1. Open chrome://extensions
2. Turn on Developer mode (top right)
3. Click Load unpacked and pick this extension folder
4. Pin the orange Kokoro Reader icon

Use
Open any Google Doc, click the icon (or press Alt+Shift+L). Reading starts and each word highlights as it is spoken.
Alt+Shift+P plays or pauses. Click any word to jump there. Space, left and right arrows work inside the panel.

Voice server
Needs the local Kokoro server at http://localhost:8880 (starts at login after running ~/kokoro/install-autostart.sh).
Default voice: af_heart+af_sarah. Change it in the gear menu.
If the doc text cannot be fetched, the panel lets you paste text instead.
