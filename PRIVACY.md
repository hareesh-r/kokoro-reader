# Privacy Policy

Kokoro Reader does not collect, store or send your data anywhere.

- The extension runs only on Google Docs pages (`docs.google.com/document`). It reads the text of the document you have open, using your own signed in Google session, so it can read it aloud.
- That text is sent only to the voice server on your own computer (`localhost`, default port 8880). It is never sent to any other server.
- Settings (voice, speed, colors, server address) are saved in your browser with Chrome storage.
- There are no analytics, no accounts, no ads and no remote code.
- The Copy debug report button copies timings and match scores to your clipboard. It has no document text. Nothing is sent unless you paste it somewhere yourself.

Questions: open an issue at https://github.com/hareesh-r/kokoro-reader/issues
